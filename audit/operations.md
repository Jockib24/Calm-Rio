## Calendar & iCal Synchronization

### Current Status
- All three listings are on Airbnb only.
- No verified Booking.com, Vrbo, Expedia, or direct website presence.
- iCal export/import URLs are not publicly accessible.

### Recommended Synchronization Strategy

1. **Primary calendar:** Use Airbnb as the master or adopt a channel manager (e.g., Smoobu, Lodgify, Guesty).
2. **Export Airbnb iCal:** Settings → Availability → Calendar sync → Export calendar.
3. **Import into Booking.com / direct site:** Paste Airbnb iCal URL into each platform.
4. **Refresh frequency:**
   - Airbnb ↔ Booking.com: every 15–60 minutes (platform-dependent)
   - Direct site iCal: refresh hourly
5. **Conflict prevention:**
   - Use instant booking only where calendars are synced.
   - Add buffer nights between turnovers if only one cleaning team.
   - Manually block owner-use dates in all calendars.

### Booking Rules
- Minimum stay: 2 nights low season, 7 nights peak.
- Preparation time: 4–5 hours between checkout and check-in.
- Same-day turnover: avoid if possible.
